## 第 0 步:安装

### 系统要求

- Android 8.0 (Oreo, API 26) 或更高
- 至少 200 MB 可用空间
- 不支持已 Root 设备上的隔离(技术上来说仍可运行,但**强烈不建议**)

### 安装方式

| 渠道 | 操作 |
| --- | --- |
| F-Droid | 暂未上架,见 [Releases](../../releases) |
| GitHub Releases | 下载 `app-debug.apk` → 允许"安装未知来源" |
| 侧载 | `adb install -r app-debug.apk` |

## 第 1 步:首次启动

### 1.1 计算器伪装

打开 App 后,看到的是一个**正常外观的计算器**:

```
┌────────────────────────┐
│              0         │
├────┬────┬────┬─────────┤
│ C  │ ±  │ %  │   ÷     │
├────┼────┼────┼─────────┤
│ 7  │ 8  │ 9  │   ×     │
├────┼────┼────┼─────────┤
│ 4  │ 5  │ 6  │   −     │
├────┼────┼────┼─────────┤
│ 1  │ 2  │ 3  │   +     │
├────┴────┼────┼─────────┤
│   0     │ .  │   =     │
└─────────┴────┴─────────┘
```

按任何键都按正常计算器工作(支持 `+ − × ÷`、小数、`C` 清零)。

### 1.2 触发隐藏入口

在计算器上**依次**按键:

```
1   2   3   +   4   5   6   =
```

> 注意:必须正好是这 8 个按键的序列。任何中间错误都需要按 `C` 清空再重试。

按下 `=` 后,屏幕会立即跳到 **设置密码** 界面。

### 1.3 设置 6 位数字密码

1. 输入您的 6 位数字密码(避免使用 `123456`、`111111` 等常见组合)
2. 点击屏幕下方"确认"或等待 6 位自动提交
3. **再次输入** 以确认(防止输错)
4. 设置成功后,自动进入主界面

> ⚠️ **请牢记您的密码**。本应用不存储明文密码,无任何"忘记密码"后门。
> 忘记密码 = 永远失去所有加密数据。

### 1.4 可选:启用指纹

如果您的设备有指纹硬件,锁屏界面会出现一个**蓝色指纹按钮**。
点击后,系统弹出 BiometricPrompt;授权后即可用指纹解锁。

> 注意:首次仍需设置数字密码。指纹解锁是"便捷"选项,不是替代品。

## 第 2 步:导入媒体

### 2.1 打开主界面

解锁后看到:

```
┌──────────────────────────────┐
│  私密空间            [🔒]    │  ← 顶栏
├──────────────────────────────┤
│                              │
│      暂无图片,点击右下角 +   │  ← 占位
│                              │
│                              │
│                       ┌───┐  │
│                       │ + │  │  ← FAB
│                       └───┘  │
├──────────────────────────────┤
│  🖼 图片  │ 🎬 视频 │ ⚙ 设置│  ← 底部导航
└──────────────────────────────┘
```

### 2.2 切换到"图片"或"视频" Tab

点击底部导航的 **图片** 或 **视频**。

### 2.3 点击右下角 + 按钮

弹出系统 **Photo Picker**(无需任何运行时权限):

```
┌──────────────────────────────┐
│  取消        选择(3)         │
├──────────────────────────────┤
│  [□] [□] [□] [□] [□] ...     │
│                              │
│  系统相册的所有图片/视频缩略图│
└──────────────────────────────┘
```

多选您想导入的文件(可一次选 50 个),点击右上角"选择"。

### 2.4 二次确认弹窗

```
┌──────────────────────────────┐
│       彻底删除原文件          │
├──────────────────────────────┤
│  原文件将从系统相册中彻底     │
│  删除,仅保留在私密空间内,    │
│  确认吗?                    │
├──────────────────────────────┤
│      [仅导入]      [确认]    │
└──────────────────────────────┘
```

- **仅导入** —— 复制到 App 私有目录,但**不**删除原文件
- **确认** —— 复制 + 稍后弹出系统删除授权弹窗

> ⚠️ 一旦选择"确认",删除需要您再授权一次(系统弹窗)。**误授权将删除原图!**

### 2.5 等待导入完成

进度由顶部 loading 遮罩表示。导入完成后:
- 网格中立即出现新缩略图
- 弹出系统"删除这些项目吗?"对话框
- 选"删除" → 原图从相册彻底消失;选"取消" → 原图保留

## 第 3 步:查看与播放

### 3.1 图片

- **网格** —— 列表中点任意图片 → 进入全屏
- **全屏** ——
  - **双指缩放**:1x - 5x
  - **滑动切换**:左右滑到上/下一张
  - **返回**:左上角 ← 按钮

### 3.2 视频

- 视频缩略图是**第一帧**(用 MediaMetadataRetriever 解密后抽帧)
- 点击视频 → 启动 ExoPlayer
- **播放控制**:
  - 点击屏幕 → 显示/隐藏控制条
  - 拖动进度条 → 跳转
  - 双击 → 倍速

> 解密过程**完全在内存**中,不写任何 `.mp4` / `.tmp` 明文文件。

## 第 4 步:移出私密空间

> 即"恢复加密文件到系统相册"。

### 操作

1. **长按** 网格中的图片或视频
2. 弹出确认框:
   ```
   移出私密空间?
   文件将被解密并恢复到系统相册,不再受密码保护。
   [取消]  [移出]
   ```
3. 选"移出" → App 立即:
   - 流式解密 .enc 文件
   - 写入 DCIM/PrivateVault/ 目录
   - 删除 .enc 加密文件

### 后果

- 文件**恢复为明文** JPG/MP4 存于系统相册
- 其他人可以通过相册 App 看到
- App 中的加密副本消失

> ⚠️ 移出后,文件回到系统相册(明文)。如需再次隐藏,重新走"导入"流程。

## 第 5 步:备份到电脑

> **强烈推荐** 定期备份。卸载 App / 清除数据 = 永久丢失!

### 5.1 加密导出到手机 Download 目录

1. 切到 **设置** Tab
2. 点击 **加密导出到 Download**
3. 输入您的 6 位数字密码
4. 点击 **开始导出**

成功后,文件保存到:
```
/storage/emulated/0/Download/PrivateVault/PrivateVault_Backup_20260607_153045.zip
```

> `.zip` 实际上是一个**加密二进制 blob**(格式见 [CRYPTO.md](CRYPTO.md#加密备份格式))。

### 5.2 拷贝到电脑

通过 USB / 邮件 / 网盘 把 `.zip` 文件传到电脑。

### 5.3 恢复(需桌面工具)

> ⚠️ **桌面恢复工具暂未开源**(在其他仓库)。
> 您需要自行实现:用 PBKDF2 派生密钥 → AES-CTR 解密 → 解压。

或者:在手机上**重新安装**本 App,设置**同样的密码**,
然后手动把 `.zip` 解密后的 `.enc` 文件复制到新 App 的 `filesDir/private_media/`
对应子目录。**注意:这种方式下,加密用的是您当前的 KDF 盐,
与备份时不同,所以无法直接还原**。

> 这是设计取舍:每次设置密码时生成新 KDF 盐,不同设备/不同密码的加密互不兼容。
> 真正可移植的备份方案需要"密码 + 盐一起导出",
> 但这会增加密码泄露风险,故当前版本未实现。

### 5.4 备份频率建议

| 使用强度 | 建议频率 |
| --- | --- |
| 偶尔 | 每月 1 次 |
| 每周都导入新内容 | 每周 1 次 |
| 大量导入 | 每次大批量导入后 |

## 第 6 步:伪装设置

### 6.1 关闭伪装

1. 切到 **设置** Tab
2. 找到 **伪装** 开关
3. **关闭** → 桌面上的"计算器"图标消失,只剩下"PrivateVault"图标
4. 下次启动 → 直接显示锁屏

### 6.2 重新启用伪装

1. 启动 App(显示锁屏)
2. 解锁后 → 设置 → 伪装 → 打开
3. 桌面上"计算器"图标重新出现

### 6.3 修改触发序列

当前版本触发序列硬编码为 `123+456=`。
如需修改,改 `CalculatorScreen.kt` 中的:
```kotlin
if (keyBuffer.toString().endsWith("123+456=")) {
```
以及 README 文档同步。

> 注意:不要用太短的序列(如 `1+1=`),容易被他人偶然触发。

## 常见问题

### Q1: 忘记密码怎么办?

**A**:无法找回。所有加密数据使用您密码派生的密钥,密码错 = 文件永久不可读。
**请养成备份习惯**!

### Q2: 升级到新版本会丢数据吗?

**A**:不会。加密文件和应用数据都在 `filesDir/` 和 `shared_prefs/`,升级是覆盖 APK,
不会被清除(除非您主动卸载或"清除数据")。

### Q3: 可以多设备同步吗?

**A**:目前**没有云同步**。每个设备的 KDF 盐不同,即使同一密码加密的密文也不通用。
如需多设备访问,建议:
1. 在设备 A 上导出加密备份
2. 在设备 B 上安装并设置**相同密码**
3. 自行实现桌面工具,把备份解密后,把 `.enc` 文件复制到 B 设备
   `Android/data/com.example.privatevault/files/private_media/`

### Q4: 我想加音频/文档支持,怎么做?

**A**:本项目预留了扩展点:
1. 在 `VaultRepository.MediaType` 加 `AUDIO("audios")`
2. 在 `MainScreen.MainTab` 加 `AUDIO` tab
3. `MediaViewModel.guessType()` 处理 `audio/*` mime

参考 [API.md](API.md#添加新文件类型)。

### Q5: 视频画质会受损吗?

**A**:不会。**AES-CTR 是无损加密**,解密后字节流与原始完全一致。
视频/图片的画质/分辨率取决于您导入的原始文件。

### Q6: 卸载 App 后再装,还能恢复吗?

**A**:**能**,但您需要:
- 之前的加密备份文件(`.zip`)
- 您的 6 位数字密码
- 桌面恢复工具(自行实现或等待开源)

否则:**永久丢失**。

### Q7: 这个 App 安全吗?比 X 强吗?

**A**:见 [SECURITY.md](SECURITY.md) 的威胁模型。简短答案:
- 6 位数字密码熵仅 20 bit,**仅防普通人**,不防专业取证
- 加解密实现遵循 NIST / OWASP 最佳实践
- **不**支持云同步、**不**支持远程擦除、**不**支持密码找回

### Q8: 如何从 GitHub 报告 Bug?

[GitHub Issues](../../issues) → New Issue → 选"Bug report"模板。

## 紧急情况

### 我输错 5 次,被锁了 30 秒

等待 30 秒,会自动解锁。期间**不要重启 App**,否则计时重置。

### 我点了"确认"但后悔了

- 如果系统删除弹窗还没出现 → App 内部有 1-2 秒延迟,这时可以**立即杀进程**(`adb shell am force-stop com.example.privatevault` 或 设置 → 应用 → 强制停止)
- 系统删除弹窗出现但还没确认 → 选"取消"
- 已经确认删除 → 无法撤销,**请检查回收站或专业恢复软件**(本 App 不提供回收站)

### App 一直闪退

1. 检查 Android 版本 ≥ 8.0
2. 清除数据后再试(会丢失所有加密内容):设置 → 应用 → PrivateVault → 存储 → 清除数据
3. 提交 [Bug Report](../../issues/new?template=bug_report.md) 附 logcat

### 我发现一个安全问题

**请勿** 在公开 Issue 写!用 [Security Advisories](../../security/advisories/new) 私下通知维护者。
详见 [SECURITY.md](SECURITY.md#披露策略)。
